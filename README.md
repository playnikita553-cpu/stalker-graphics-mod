# S.T.A.L.K.E.R.: Тень Чернобыля — Realistic Graphics Mod

Графический мод для S.T.A.L.K.E.R.: Shadow of Chernobyl, улучшающий освещение, погоду и визуальные эффекты. Совместим с патчем 1.0006.

## Возможности

### Реалистичное освещение и погода
- **24-часовой цикл освещения** с плавными переходами — рассвет, полдень, закат, ночь
- **Реалистичные цвета неба** для каждого времени суток
- **Улучшенные ночи** — тёмные, атмосферные, с холодными тонами
- **Золотой час** на рассвете и закате с тёплыми оранжевыми тонами
- **Атмосферный туман** с правильным затуханием
- **Реалистичный дождь и грозы** с молниями и ветром
- **Три типа погоды**: ясно, дождь, туман — каждый с полным суточным циклом

### Улучшенные шейдеры
- **Enhanced Bloom** — мягкое свечение ярких источников света с 13-тап фильтром
- **Depth of Field** — кинематографическая глубина резкости с эффектом боке
- **Volumetric Sun Shafts** — объёмные лучи солнца (God Rays) через деревья и здания
- **Color Grading** — кинематографическая цветокоррекция в стиле Зоны
- **Enhanced Shadows** — мягкие тени с PCF-фильтрацией и затуханием контакта
- **ACES Tone Mapping** — кинематографическое тональное отображение
- **Виньетирование** — тонкое затемнение по краям экрана

## Установка

### Способ 1: Автоматическая (Windows)
1. Скачайте или клонируйте этот репозиторий
2. Запустите `install.bat` **от имени администратора**
3. Укажите путь к игре (или используйте путь по умолчанию для Steam)

### Способ 2: Ручная
1. Скопируйте папку `gamedata` в корневую директорию игры:
   ```
   C:\Program Files (x86)\Steam\steamapps\common\S.T.A.L.K.E.R. Shadow of Chernobyl\
   ```
2. Откройте файл `fsgame.ltx` в корне игры и измените:
   ```
   $game_data$ = false| true| $fs_root$| gamedata\
   ```
   на:
   ```
   $game_data$ = true| true| $fs_root$| gamedata\
   ```
3. (Опционально) Скопируйте рекомендованные настройки из `recommended_settings.ltx` в ваш `user.ltx`

### Где находится user.ltx?
```
%USERPROFILE%\Documents\stalker-shoc\user.ltx
```

## Рекомендованные настройки

Для наилучшего результата используйте **рендерер R2 (DirectX 9 Enhanced)**.

Ключевые настройки (подробнее в `recommended_settings.ltx`):
```
renderer renderer_r2
r2_sun on
r2_sun_details on
r2_sun_focus on
r2_tonemap on
r2_ls_bloom_fast on
r2_ls_bloom_threshold 0.2
r2_ls_bloom_kernel_scale 0.8
r2_sun_lumscale 1.0
r2_sun_lumscale_amb 1.0
r2_sun_lumscale_hemi 1.0
```

## Структура мода

```
gamedata/
├── config/
│   └── environment/
│       └── weathers/
│           ├── weather_default.ltx    # Ясная погода (24ч цикл)
│           ├── weather_rain.ltx       # Дождь и гроза (24ч цикл)
│           └── weather_foggy.ltx      # Туман (24ч цикл)
└── shaders/
    └── r2/
        ├── bloom_build.h              # Извлечение ярких областей
        ├── bloom_filter.h             # Размытие и комбинирование bloom
        ├── dof.h                      # Глубина резкости
        ├── sun_shafts.h               # Объёмные лучи солнца
        ├── color_grading.h            # Цветокоррекция
        ├── enhanced_shadows.h         # Улучшенные тени
        └── combine_postprocess.h      # Финальный пост-процессинг
```

## Удаление мода

1. Удалите папку `gamedata` из директории игры
2. Верните `fsgame.ltx` в исходное состояние:
   ```
   $game_data$ = false| true| $fs_root$| gamedata\
   ```
3. Или просто **проверьте целостность файлов** через Steam:
   - ПКМ по игре → Свойства → Установленные файлы → Проверить целостность

## Совместимость

- **Версия игры**: 1.0004 / 1.0005 / 1.0006
- **Рендерер**: R2 (Static Lighting) или R2 (Full Dynamic Lighting)
- **Совместимость с другими модами**: Мод заменяет только файлы погоды и шейдеры. Совместим с модами, которые не изменяют эти файлы.

## Известные проблемы

- На слабых видеокартах bloom и DOF могут снизить FPS. Отключите через `user.ltx`:
  ```
  r2_ls_bloom_fast off
  ```
